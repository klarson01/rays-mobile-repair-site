# Customer-managed website photos

These folders are reserved for photos Ray can replace without editing page code.

## Folder layout

- `home/` — homepage photos
- `services/` — services page photos
- `fleet/` — fleet-service page photos
- `about/` — about page photos
- `careers/` — careers page photos
- `contact/` — contact page photos

For the first version, Ray will replace a photo with another image using the same filename. The site configuration will later be pointed to these managed files after the initial images are placed and tested.

Do not rename or delete managed image files once the site is wired to them unless the corresponding site configuration is also updated.
